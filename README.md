# Texas Net Migration Analysis (1950–2020)

## Overview
This project analyzes net migration trends across major Texas counties using historical U.S. county migration datasets from 1950–2020.

The project focuses on:
- Migration trend analysis
- County-level comparison
- Data visualization
- Machine learning forecasting
- Interactive analytics dashboard

## Counties Analyzed
- Travis County
- Harris County
- Dallas County

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Plotly
- Scikit-learn
- Streamlit

## Features
- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Migration trend visualization
- County comparison analysis
- Forecasting future migration trends
- Interactive dashboard

## Dataset
Dataset Source:
https://netmigration.wisc.edu/
