# 📊 Travis County Net Migration Analysis (2010–2020)

A data analysis project exploring **who moved into and out of Travis County, Texas** during the 2010s — broken down by race/ethnicity, age group, and gender — using the University of Wisconsin's Net Migration Estimates (NME) dataset.

---

## 🔍 What This Project Does

Travis County (Austin, TX) has been one of the fastest-growing counties in the United States. This project digs into the *structure* of that growth: which demographic groups drove in-migration, which age cohorts left, and how the county's observed 2020 population compares to what would have existed without any migration at all.

Specifically, the analysis covers:

- **Population composition** by race/ethnicity and age (2020 census)
- **Net migration counts** — how many people from each group moved in or out during the 2010s
- **Net migration rates** — normalized rates that make groups comparable regardless of size
- **Age pyramids** showing the county's demographic structure by sex
- **Observed vs. expected population** — quantifying migration's actual impact on each age cohort
- **Gender gaps** in migration by age group
- **Interactive visualizations** via Plotly for exploratory deep-dives

## 📦 Dataset

**Source:** [Net Migration Estimates — University of Wisconsin Applied Population Laboratory](https://netmigration.wisc.edu/)

**Dataset used:** `NME_1020` — county-level net migration estimates for the 2010–2020 decade

**Coverage:** All U.S. counties · 5-year age groups (0–4 through 85+) · 5 race/ethnicity groups · Both sexes

**County of focus:** Travis County, Texas · FIPS `48453`

### Variable Structure

Raw variables follow the pattern `[period][race][sex][age]`:

| Component | Codes | Meaning |
|-----------|-------|---------|
| **Period** | `f1` `m1` `e1` `r1` | Population 2020 · Net Migrants 2010s · Expected Pop 2020 · Net Migration Rate |
| **Race** | `wn` `bn` `th` `an` `it` `tt` | White NH · Black NH · Hispanic · Asian/PI · Am. Indian · Total |
| **Sex** | `f` `m` `t` | Female · Male · Total |
| **Age** | `0` `5` `10` … `85` | Start of 5-year age group |

Example: `m1bntf25` = Net migrants, Black non-Hispanic, Total sex, ages 25–29.

## 🚀 Getting Started

### Prerequisites

Python 3.8+ is required. Install dependencies with:

```bash
pip install pandas numpy matplotlib seaborn plotly
```

Or via requirements file:

```bash
git clone https://github.com/yourusername/travis-county-nme-analysis.git
cd travis-county-nme-analysis
pip install -r requirements.txt
```

### Running the Notebook

**Option A — Google Colab (recommended):**

1. Open `Travis_County_NME_Analysis.ipynb` in [Google Colab](https://colab.research.google.com/)
2. Upload `NME_1020_data.zip` when prompted in Step 2
3. Run all cells in order

**Option B — Local Jupyter:**

1. Download `NME_1020_data.zip` from [netmigration.wisc.edu](https://netmigration.wisc.edu/) and place it in the project root
2. Extract the ZIP (it contains `NME_1020_data.csv` and `NME_1020_datadict.csv`)
3. Skip the Colab upload cell and run from Step 3 onward
